# Catálogo de Telas – Creaciones Solo Punto

Sitio web estático que muestra el catálogo de telas de Creaciones Solo Punto. El visitante puede filtrar las telas por categoría, buscarlas por nombre o código y abrir cada una en un visor de tamaño grande, que muestra su nombre, código y categoría.

Está hecho con HTML, CSS y JavaScript puro, sin dependencias ni proceso de compilación, así que funciona abriéndolo directamente en el navegador o publicándolo en cualquier hosting estático como GitHub Pages.

Cada tela tiene un código propio y los filtros con sus contadores se generan automáticamente a partir de los datos del catálogo, por lo que agregar o quitar telas y categorías no requiere tocar el diseño.
